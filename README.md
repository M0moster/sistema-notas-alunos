# Sistema de Notas de Alunos

Programa de console em Python para cadastrar alunos, lançar duas notas
e calcular a média com a situação (Aprovado, Recuperação ou Reprovado).

## Funcionalidades
- Cadastro de alunos
- Lançamento de notas (prova 1 e prova 2)
- Cálculo de média e situação
- Exibição dos resultados da turma

## Como executar
Requer Python 3.

python main.py

## Conceitos praticados
Funções, dicionários, listas, condicionais e entrada de dados.
